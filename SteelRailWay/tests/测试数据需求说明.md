## 详细说明

### 1. 黑盒测试（88个用例）

**测试目标**：参数验证、边界值、等价类划分

**数据策略**：使用 pytest 的 `tmp_path` fixture 创建临时文件系统

#### 示例代码：
```python
def test_view_id_valid_range(self, tmp_path):
    """测试 view_id 的有效范围"""
    # 创建临时目录结构（不需要真实图像）
    train_root = str(tmp_path / "train")
    test_root = str(tmp_path / "test")
    
    # 创建必需的目录结构
    (tmp_path / "train" / "Cam1" / "rgb").mkdir(parents=True, exist_ok=True)
    (tmp_path / "train" / "Cam1" / "depth").mkdir(parents=True, exist_ok=True)
    
    # 实例化数据集（不加载实际数据）
    dataset = RailDualModalDataset(
        train_root=train_root,
        test_root=test_root,
        view_id=1,
        split="train"
    )
    
    assert dataset.view_id == 1  # 只验证参数
```

**关键点**：
- 只测试参数验证逻辑
- 不需要实际加载图像数据
- 使用临时目录 `tmp_path`
- 测试完成后自动清理

### 2. 白盒测试（84个用例）

**测试目标**：语句覆盖、分支覆盖、条件覆盖、路径覆盖

**数据策略**：使用 PyTorch 生成随机张量

#### 示例代码：
```python
def test_loss_l2_normal_input(self):
    """测试 L2 损失函数"""
    # 使用随机张量（不需要真实特征）
    feature_1 = torch.randn(4, 256, 56, 56)
    feature_2 = torch.randn(4, 256, 56, 56)
    
    # 测试损失计算
    loss = loss_l2(feature_1, feature_2)
    
    assert loss.item() >= 0  # 验证损失非负
    assert not torch.isnan(loss)  # 验证无 NaN
```

**关键点**：
- 使用 `torch.randn()` 生成合成数据
- 测试函数逻辑和边界情况
- 不需要真实的模型权重
- 专注于代码覆盖率

## 常见问题

### Q1: 为什么测试不需要真实数据？
**A**: 当前测试专注于**代码逻辑验证**，而非**功能验证**。使用mock数据可以：
- 快速运行（5秒 vs 数小时）
- 易于维护（无需数据管理）
- 可重复（无环境依赖）

### Q2: 跳过的11个测试是什么？
**A**: 需要GPU的CUDA测试，例如：
```python
@pytest.mark.skipif(not torch.cuda.is_available(), reason="需要CUDA")
def test_cuda_memory():
    # GPU相关测试
```

### Q3: 如何验证模型的实际性能？
**A**: 需要在Phase 3添加集成测试，使用真实数据。当前Phase 1-2只验证代码正确性。

### Q4: 测试覆盖率96%是如何达到的？
**A**: 通过白盒测试的路径覆盖，使用合成数据触发所有代码分支。

# 测试数据说明

现有64项测试不依赖真实钢轨数据、模型权重或完整训练。共享 `rail_factory` 在 pytest 的 `tmp_path` 中创建 `Cam1/rgb/*.jpg` 和 `Cam1/depth/*.tiff`；图像为16×24，深度由已知递增数组构造。测试按需求另建测试目录、GT或损坏输入。

- 黑盒：用合法/非法参数、采样边界、预加载与延迟加载、RGB/depth/GT空间对齐建立预期；缺失文件通过扫描后删除文件复现。
- 白盒：使用合成张量和小模型验证损失数值、梯度、参数量和误报计数；时延回归使用受控时钟，实际时延用例仍受机器计时影响。
- AI辅助：Hypothesis生成参数和值；常量归一化为零、log1p数值、通道一致性、访问顺序不变性和预加载一致性来自明确数学性质。

共享fixture每个用例重置随机种子为42，设备为CPU。临时输出通过 `tmp_path`/`tmp_path_factory` 隔离。无掩码时全零GT是接口默认行为，不代表人工标注。

`SteelRailWay/datasets/` 是加载器源码；课程测试不能证明真实数据检测精度、完整训练或端到端验收。
